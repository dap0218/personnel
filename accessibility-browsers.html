Accessibility Options in Browsers

Every modern browser lets you make pages larger and choose a bigger default text size. These settings stay in place for all websites you visit.

Zoom any page (all browsers)

  • Press Ctrl and + to zoom in, Ctrl and - to zoom out, and Ctrl and 0 to return to normal size.
  • On a Mac, use Cmd instead of Ctrl.
  • On a phone or tablet, spread two fingers on the screen to zoom in.

Google Chrome

  1. Open the menu (three dots, top right) and select Settings.
  2. Select Appearance.
  3. Change Font size or Page zoom.

Microsoft Edge

  1. Open the menu (three dots, top right) and select Settings.
  2. Type font size or zoom in the search box at the top of the Settings page.
  3. Choose the size you want.

Mozilla Firefox

  1. Open the menu (three lines, top right) and select Settings.
  2. Under General, go to Language and Appearance.
  3. Change the Fonts size or the Default zoom.

Safari (Mac)

  1. Choose Safari > Settings.
  2. Select Websites > Page Zoom to set a larger zoom, or select Advanced and tick Never use font sizes smaller than.

High contrast colours

  • Windows: Settings > Accessibility > Contrast themes.
  • Mac: System Settings > Accessibility > Display > Increase contrast.
  • You can also use Dark Contrast in this website's Accessibility Controls panel – see Help.
